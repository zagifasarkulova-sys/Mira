# English Words Bot 🇬🇧

Telegram-бот для изучения английских слов уровня B1-B2.

## Что умеет

- Утром в 9:00 (Актобе) присылает 5 новых слов от Claude
- Вечером в 20:00 — квиз по словам дня
- Ведёт streak и статистику
- Работает для нескольких пользователей

## Переменные окружения

```
BOT_TOKEN=токен от @BotFather
ANTHROPIC_API_KEY=ключ Claude API
DATABASE_URL=postgresql://user:pass@host/dbname
```

## Деплой на Render

1. Создай PostgreSQL базу на Render
2. Создай Web Service (Docker), укажи переменные окружения
3. Задеплой

## Команды бота

| Команда | Описание |
|---------|----------|
| /start | Регистрация |
| /words | Слова на сегодня |
| /quiz | Пройти квиз сейчас |
| /stats | Прогресс и статистика |
